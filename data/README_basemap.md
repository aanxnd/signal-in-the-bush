# Bundled geographic context

basemap_countries.geojson is a reduced regional subset of Natural Earth 1:110m Admin 0 Countries. It contains Mali and seven neighboring countries; properties retain ADMIN and the source label coordinates. Coordinates and borders are approximate visualization context, not surveyed deployment boundaries.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson

Natural Earth data are public domain: https://www.naturalearthdata.com/about/terms-of-use/

Retrieved 2026-10-11. Rendering embeds this data into demo/map.html and makes no requests to tile servers. Leaflet/jQuery assets and their separate licenses are retained under demo/assets/. This file is unrelated to the elephant observation data and does not affect placement metrics.
